# Counter Pro

Counter Pro is a simple frontend project built with HTML, CSS, and Vanilla JavaScript.

This project was created to practice DOM manipulation, event handling, conditional logic, and UI updates without using any framework.

---

## Features

- Increase and decrease counter
- Reset button
- Minimum and maximum limits
- Dynamic text colors
- Disabled buttons at limits
- Error messages for max/min reached
- Simple button animations
- Responsive and clean layout

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## Concepts Practiced

- DOM selection
- `addEventListener()`
- `textContent`
- Functions
- Conditional logic
- UI state management
- CSS transitions
- Dynamic styling
